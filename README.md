# Instagram Theme Song

Standalone MVP for an owner-selected theme song experience associated with an Instagram profile.

## What this repository contains
- Instagram connection placeholder
- Profile owner handle and theme-track selection
- Playback behavior selection
- Mobile-style profile preview
- Local prototype settings persistence
- Clear boundary for future Meta/Instagram API integration

## Development path
GitHub is the source of truth. The app is intentionally framework-free HTML/CSS/JS so it can be deployed as a static Vercel project.

## Integration boundary
This MVP demonstrates the experience outside the Instagram client. Direct Instagram profile audio requires capabilities, permissions, and review supported by Meta's current APIs. It does not claim to inject or autoplay audio inside Instagram itself.
